แบบสำรวจรายการรายได้ที่จ่ายผ่าน Payroll

สำหรับ Project Controller / Project Admin ตรวจสอบว่ารายการรายได้ของพนักงานแต่ละตำแหน่งในโครงการ ต้องนำมาคำนวณเป็นฐานค่าจ้างกองทุนสงเคราะห์ลูกจ้างหรือไม่ และรายการใดควรปรับเงื่อนไขการจ่าย หรือย้ายไปเบิกกับฝ่ายบัญชี

กำหนดส่ง 30 กันยายน 2569 เริ่มหักเงินสะสม รอบค่าจ้างเดือนตุลาคม 2569 อัตราเงินสะสม/สมทบ ฝ่ายละ 0.25% สอบถาม ฝ่ายทรัพยากรบุคคล

กำลังตรวจสอบสิทธิ์…

แบบสำรวจนี้เปิดให้เฉพาะอีเมลที่ฝ่ายทรัพยากรบุคคลกำหนดไว้เท่านั้น

ข้อมูลโครงการและผู้กรอก

ระบุชื่อโครงการตามที่ใช้เรียกภายใน ไม่ต้องกรอกชื่อพนักงานรายบุคคล

เกณฑ์ที่ใช้ตัดสิน

ระบบจะจัดประเภทให้อัตโนมัติจากลักษณะการจ่ายที่ท่านเลือก ตามหลักเกณฑ์ของกรมสวัสดิการและคุ้มครองแรงงาน อ้างอิง พ.ร.บ. คุ้มครองแรงงาน พ.ศ. 2541

เข้าเกณฑ์ฐานค่าจ้างไม่เข้าเกณฑ์
เงินตอบแทนการทำงานในเวลาปกติ · จ่ายประจำตามระยะเวลาหรือตามผลงานในเวลาปกติ · เงินที่ได้รับในวันหยุดและวันลาตามสิทธิ ค่าล่วงเวลาและค่าทำงานในวันหยุด · โบนัสและเงินรางวัลครั้งคราว · เงินจูงใจที่มีเงื่อนไข/เป้าหมายชัดเจน · เงินชดเชยค่าใช้จ่ายที่เบิกตามจริงและมีหลักฐานตามหลักบัญชี
นับเป็นฐานค่าจ้าง หัก 0.25% เข้ากองทุน ต้องปรับเงื่อนไข ปัจจุบันเข้าข่ายฐานค่าจ้าง ไม่นับเป็นฐานค่าจ้าง ต้องมีเอกสารรองรับ

ตำแหน่งงานในโครงการ

เพิ่มทีละตำแหน่ง แล้วกรอกรายการรายได้ทุกรายการที่จ่ายจริงให้ตำแหน่งนั้น รวมรายการที่จ่ายเป็นครั้งคราวด้วย

สรุปผลการจัดประเภท

ตรวจความถูกต้องก่อนส่ง ยอดฐานค่าจ้างเป็นประมาณการต่อเดือนต่อคน ใช้สำหรับประเมินผลกระทบเท่านั้น

ส่งข้อมูลกลับให้ฝ่ายทรัพยากรบุคคล

กด “ส่งข้อมูลให้ HR” เพื่อบันทึกเข้าระบบ หรือจะดาวน์โหลด CSV และส่งทางอีเมลเพิ่มก็ได้ เมื่อส่งแล้วยังกลับมาแก้ไขและส่งใหม่ได้ด้วยรหัสอ้างอิงเดิม

ไฟล์ CSV เปิดด้วย Excel ได้ทันที แนบส่งอีเมลหรือกลุ่มงานให้ฝ่ายทรัพยากรบุคคล พร้อมเก็บแฟ้มเอกสารประกอบตามที่ระบบแจ้งไว้ในแต่ละรายการ
รายการรายได้ที่ต้องเตรียมเอกสาร และผู้รับผิดชอบ
  • ค่าน้ำมัน / ค่าที่พัก / ค่าทางด่วน / ค่าไปรษณีย์ / ค่าโทรศัพท์ — จ่ายตามจริงพร้อมใบเสร็จรับเงินในนามบริษัท ใบขอเบิก และ Traveling ส่งทุกวันอังคารหรือตามรอบที่ฝ่ายบัญชีกำหนด ผู้จ่าย: ฝ่ายบัญชี
  • Incentive / Commission — ต้องมี Scheme การจ่ายและเป้าการขาย สรุปทุกเดือน เก็บไว้พร้อมตรวจได้ทุกเมื่อ ผู้ดำเนินการ: Admin Project ส่ง HR
  • เบี้ยขยัน / ค่าตอบแทนกิจกรรม Demo / Tasting / ค่าโฟน — ต้องมี Scheme ที่มีเป้าขั้นต่ำ ทำถึงจึงได้รับ ผู้จ่าย: ฝ่ายบัญชี
  • เบี้ยเลี้ยง — จ่ายเฉพาะเมื่อออกไปปฏิบัติงานนอกสถานที่จริง หยุดจ่ายเมื่อไม่มีการเดินทาง ผู้จ่าย: ฝ่ายบัญชี
  • ค่าสึกหรอรถ / ค่าเสื่อม / ค่าให้บริการต่างๆ — คำนวณตามการใช้รถเพื่อปฏิบัติงานจริง มี Mileage Log ใบเสร็จค่าบำรุงรักษา และรายงานการเดินทาง ผู้จ่าย: ฝ่ายบัญชี
  • ค่าเช่ารถ — ต้องมีสัญญาเช่าระบุระยะเวลาและค่าเช่าประกอบ
